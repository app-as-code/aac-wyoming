# Icon source

Icons are downloaded from the selfh.st icon collection (repository `selfhst/icons`,
served via jsdelivr). No icon was drawn or modified by hand.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `svg/rhasspy.svg` | Default (fallback) |
| `icon-light.svg` | `svg/rhasspy-dark.svg` | Dark-colored logo for light backgrounds |
| `icon-dark.svg` | `svg/rhasspy-light.svg` | Light-colored logo for dark mode |

Download URLs:

- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/rhasspy.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/rhasspy-dark.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/rhasspy-light.svg
